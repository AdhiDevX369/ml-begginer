## 3. Loss – "මම කොච්චර වැරදිද?" (loss එක හොයන්නේ ඇයි කියන ප්‍රශ්නයට උත්තරය)

```python
def loss(w):
    y_hat = predict(w)
```
🗣️ "y_hat = model එකේ අනුමානය."

```python
    error = y - y_hat
```
🗣️ "error = ඇත්ත – අනුමානය. ගෙයක් ගානේ කොච්චර වැරදුනාද."

```python
    return np.mean(error ** 2)
```
🗣️ "Square කරන්නේ ඇයි? (1) + සහ – error එකිනෙක cancel වෙන එක නවත්තන්න. (2) ලොකු වැරදි වලට ලොකු දඬුවමක් දෙන්න.
ඊට පස්සේ mean – හැම ගෙයක්ම එකතු කරලා **එක අංකයක්.** මේ තමයි ගිය සතියේ ඉගෙනගත්ත **MSE**.
මතක තියාගන්න: **loss කියන්නේ model එකට දෙන ලකුණු. අඩු වෙන තරමට හොඳයි.**"

```python
print(loss(10))

```
🗣️ "w=10 → 286, w=20 → 4.4, w=30 → 170.
දැන් එක ඇහැට පේනවා **w = 20 තමයි හොඳම එක** කියලා. Loss එක නැතුව අපිට මේක කියන්න බැහැ.
👉 **Loss එක හොයන්නේ ඇයි?** – 'හොඳයි/නරකයි' කියන එක computer එකට තේරෙන **අංකයක්** කරන්න."

## 5. Slope – "කොයි පැත්තටද යන්න ඕනේ?" (slope එක බලපාන්නේ මොකටද කියන ප්‍රශ්නයට උත්තරය)

```python
def slope(w, h=0.001):
```
🗣️ "h = ගොඩක් පොඩි තල්ලුවක්."

```python
    return (loss(w + h) - loss(w)) / h
```
🗣️ "w එක පොඩ්ඩක් (h) වැඩි කරලා බලනවා loss එක කොච්චර වෙනස් වුණාද කියලා.
**Slope = 'මම w එක පොඩ්ඩක් වැඩි කළොත් loss එකට මොකද වෙන්නේ?'**
මේ තමයි derivative එකේ definition එක – f(x+h) – f(x) / h. කැම්පස් එකේ කරපු ගණනමයි, දැන් code එකෙන්."

```python
print(slope(10))
```
🗣️ "w=10 → slope = **–50**. **Minus** කියන්නේ: 'w වැඩි කළොත් loss එක **අඩු වෙනවා**'. ඉතින් **w වැඩි කරන්න ඕනේ.** ගණන 50 ලොකුයි – ඒ කියන්නේ තාම යටට ගොඩක් දුරයි."

```python
print(slope(30))
```
🗣️ "w=30 → slope = **+39**. **Plus** කියන්නේ: 'w වැඩි කළොත් loss එක **වැඩි වෙනවා**'. ඉතින් **w අඩු කරන්න ඕනේ.**"

```python
print(slope(20))
```
🗣️ "w=20 → slope = **–5.8**. පොඩි අංකයක්. ඒ කියන්නේ **යටට ගොඩක් කිට්ටුයි.** හරියටම යටදි slope = 0.

👉 **Slope එකෙන් අපිට දේවල් දෙකක් කියනවා:**
- **Sign එක (+/–)** → කොයි **පැත්තටද** යන්න ඕනේ
- **Size එක** → තාම කොච්චර **දුරද**

ඇස් බැඳලා කන්දකින් බහිනවා හිතන්න. අඩිය තියලා බිම බෑවුම දැනෙනවා – ඒ තමයි slope. බෑවුම පහළට යන පැත්තට අඩිය තියනවා."

```python
lr = 0.1
```

```python
for step in range(10):
```

## 8. සම්පූර්ණ loop එක – w සහ b දෙකම (ගිය සතියේ notebook එකේ 3.6)

🗣️ "දැන් ඇත්ත model එක: **මිල = w × size + b**. b = bias, size එක 0 වුණත් තියෙන මූලික මිල (ඉඩම, වගේ).
Weights දෙකක් තියෙන නිසා slope **දෙකක්** ඕනේ – එකක් w ට, එකක් b ට. ඒ දෙක එකට තමයි **gradient** කියන්නේ. ඒ ටිකයි වෙනස."

```python
w, b = 0.0, 0.0
```
🗣️ "දෙකම 0 න් පටන් ගන්නවා."

```python
lr = 0.1
history = []
```
🗣️ "history එකේ loss එක save කරනවා – පස්සේ graph එකක් අඳින්න."

```python
for epoch in range(1000):
```
🗣️ "Epoch = data එක මුළුමනින්ම එක පාරක් බලන එක. 1000 පාරක්."

```python
    y_hat = w * x + b
```
🗣️ "**1. Predict** – දැන් තියෙන w, b එකෙන් අනුමාන කරනවා."

```python
    error = y - y_hat
    history.append(np.mean(error ** 2))
```
🗣️ "**2. Loss** – කොච්චර වැරදිද (MSE)."

```python
    dw = -2 * np.mean(x * error)
```
🗣️ "**3. Slope (w ට)** – කලින් අපි h එකෙන් approx කළා. මෙතන calculus එකෙන් හරියටම හදපු formula එක. කැම්පස් එකේ derive කරපු එකමයි. **තේරුම එකයි: 'w වැඩි කළොත් loss එකට මොකද වෙන්නේ'.**"

```python
    db = -2 * np.mean(error)
```
🗣️ "**3. Slope (b ට)** – b වැඩි කළොත් loss එකට මොකද වෙන්නේ."

```python
    w = w - lr * dw
    b = b - lr * db
```
🗣️ "**4. Update** – දෙකම පහළට අඩියක්. Section 6 එකේ line එකමයි, දෙපාරක්."

```python
print(f"w = {w:.2f}, b = {b:.2f}")
print(f"loss: {history[0]:.1f} -> {history[-1]:.3f}")
```
🗣️ "w ≈ 19.85, b ≈ 2.30. Loss එක **1015 → 0.03**.
තේරුම: 'මූලික මිල මිලියන 2.3යි, sq ft 1000කට මිලියන 19.85ක් එකතු වෙනවා.' Model එක ඒක තනියම හොයාගත්තා."

```python
plt.ylabel("loss")

plt.show()
```
🗣️ "Loss එක පහළට යන හැටි. Training එකක් හරියට යනවද කියලා බලන්න ඇත්ත ML engineers බලන graph එක මේකමයි."

```python
print(f"1600 sq ft house: {w * 1.6 + b:.1f} million LKR")
```

## 9. අවසාන සාරාංශය (board එකේ ලියන්න)

🗣️ "අද කරපු හැම දෙයක්ම පේළි 4කින්:"

| පියවර | Code එක | ඇයි? |
|---|---|---|
| 1. Predict | `y_hat = w * x + b` | දැනට තියෙන guess එකෙන් අනුමානය |
| 2. **Loss** | `mean((y - y_hat)**2)` | **කොච්චර වැරදිද කියලා එක අංකයක්** – හොඳ/නරක මනින්න |
| 3. **Slope** | `dw`, `db` | **කොයි පැත්තට, කොච්චර දුර** යන්නද කියලා දැනගන්න |
| 4. Update | `w = w - lr * dw` | ඒ පැත්තට පොඩි අඩියක් |
| Repeat | `for epoch ...` | යටට එනකම් |

🗣️ "**Calculus තියෙන්නේ step 3 එකට විතරයි.** ඒකයි slope එකේ වැදගත්කම – ඒක නැත්නම් බිලියන ගණන් weights try කරලා බලන්න වෙනවා.
ඊළඟ සතියේ (Week 3) Linear Regression එකේ `model.fit()` කරන්නෙත් **මේ loss එකම අඩුම කරන w, b හොයන එකමයි** (sklearn එක shortcut formula එකකින් කෙලින්ම හොයනවා, `SGDRegressor` නම් මේ loop එකමයි). Neural networks වල, ChatGPT වලත් – මේ පියවර 4මයි, weights ගොඩක් වැඩියි විතරයි."

### 💡 ළමයි අහන්න පුළුවන් ප්‍රශ්න

- **"Slope 0 වුණාම මොකද වෙන්නේ?"** → `w - lr * 0 = w`. w වෙනස් වෙන්නේ නැහැ. යටට ආවා. Training ඉවරයි (converged).
- **"Square නොකර absolute (|error|) ගත්තොත්?"** → පුළුවන් (MAE). හැබැයි 0 ළඟ slope එක හොඳට define වෙන්නේ නැහැ, square එක smooth නිසා calculus ලේසියි.
- **"lr එක කොහොමද තෝරන්නේ?"** → Try කරලා. Loss graph එක බලනවා: හෙමින් අඩු වෙනවා නම් වැඩි කරනවා, උඩ පනිනවා නම් අඩු කරනවා.
